# Business Insights Report

## Overview
This report summarizes the types of business insights generated from the Mercedes-Benz sales dataset.

The final values and rankings are presented through the Power BI dashboard and SQL KPI queries.

## Sales Performance Analysis
The Sales Performance Dashboard helps analyse:
- Total sales revenue
- Total quantity sold
- Total customers
- Total dealers
- Total vehicle models
- Average sale price
- Sales by manufacturing year
- Sales by transmission type

## Vehicle Analysis
The Technical Comparison page helps compare Mercedes-Benz models based on:
- Vehicle class
- Engine size
- Fuel type
- Fuel efficiency
- Listing price
- Sale price
- Vehicle mileage

## Geographic Analysis
The Geographic Analysis page helps identify:
- Sales performance by region
- Sales performance by state
- Dealer-wise sales
- Quantity sold across different locations

## Customer Analysis
Customer information can be used to compare:
- Sales by customer type
- Number of customers in each category
- Revenue contribution from different customer groups

## Time-Based Analysis
The Date Dimension supports:
- Monthly sales trends
- Quarterly sales trends
- Yearly sales analysis

## Conclusion
The project converts raw Mercedes-Benz sales data into structured Gold-layer tables and interactive Power BI dashboards.

It helps users analyse sales performance, vehicle characteristics, geographic trends, customer categories, and time-based sales patterns.
