# Mercedes-Benz Sales Performance Analytics

## Project Overview
This project analyzes Mercedes-Benz vehicle sales data using SQL, Power BI, and Data Engineering concepts.

The objective of this project is to analyze sales performance, compare vehicle models, study regional sales trends, and generate business insights through interactive dashboards.

## Business Objectives
- Analyze total sales performance
- Compare vehicle models
- Analyze fuel type distribution
- Analyze regional sales performance
- Compare transmission types
- Study manufacturing year trends

## Tech Stack
| Technology | Purpose |
|------------|---------|
| SQL | Data querying and KPI analysis |
| Databricks | Data processing |
| PySpark | Data transformation |
| Delta Lake | Data storage and versioning |
| Power BI | Dashboard and visualization |
| VS Code | Project documentation |
| Git & GitHub | Version control |
